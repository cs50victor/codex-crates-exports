Codex Crates Exports makes the Rust crates from openai/codex available as individually selectable Cargo Git dependencies. It follows upstream main daily, exposes source-defined library module paths while preserving type, field and method visibility with a syntax-aware exporter, and keeps upstream licenses and platform requirements. Procedural macros retain Rust's required export rules; macro-generated items and local implementation details are not rewritten. Use a pinned commit and a package name from _exports/crates.json; see _exports/USAGE.txt for examples and validation limits. This is an independent community derivative, not an official OpenAI distribution or a crates.io publication.
